# Сайт Кати Борисовой — исходники для переезда с Claude Artifact

Это обычный статический сайт: `index.html` + папка `web_images/` с настоящими
файлами (без base64), плюс `admin/` для редактирования текста/ссылок через
браузер после публикации.

Как запустить всё вместе — см. пошаговую инструкцию, которую Катя получила
в чате (GitHub → Netlify → домен → Identity/Git Gateway → приглашение себя
как пользователя CMS).

## Что можно менять самой через `/admin`

- роль/подпись в шапке (`heroRole`, `heroCredential`)
- четыре ссылки в блоке "Контакты" внизу сайта (email, Instagram, Telegram, MUBI)

Все остальные правки (фото, видео, тексты фильмов, вёрстка) — как и сейчас,
через Клода.
